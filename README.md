 # Student Course Management System

## About the Project

A MySQL database project for managing students, courses, enrollments, and grades. It demonstrates relational database design and practical SQL queries.

## Database Structure

The project contains three tables:

* **Student:** Stores student details, including names, majors, and ages.
* **Course:** Stores course names and credit values.
* **Enrollment:** Connects students with courses and stores their grades.

## SQL Skills Demonstrated

* Database and table creation
* Primary keys and foreign keys
* Inserting, updating, and deleting data
* Filtering with WHERE, AND, OR, and LIKE
* Sorting with ORDER BY
* Aggregate functions: COUNT, AVG, MAX, MIN, and SUM
* GROUP BY
* INNER JOIN and LEFT JOIN
* Subqueries
* Many-to-many relationships

## Project Files

* `student_management.sql` — Creates the database, tables, and sample data.
* `queries.sql` — Contains practical queries for analyzing the data.
* `ERD.png` — Shows the database relationships.

## How to Run

1. Install MySQL and open your MySQL editor.
2. Run `student_management.sql` to create the database and insert sample data.
3. Run the queries in `queries.sql` individually or together.
4. Review the results to understand how the database works.
